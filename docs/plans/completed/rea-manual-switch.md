# REA 手动开关与桌面入口

将 REA 改为当前窗口、当前终端手动开启，默认关闭。成功连接后允许向模型提供 REA 工具；关闭、取消或目标 revision 变化后拒绝执行，关闭同时取消进行中的 REA 操作。面板重新打开读取后端状态，不仅修改按钮文案。

沿用 Rust command → 类型化 bridge → renderer 边界，保留原有 AI 模式、审批和 SSH 认证约束。更新使用说明，执行项目门禁与开关专项验证、当前源码桌面验收，重新编译 Windows 软件。在桌面创建指向完整发行目录的 transterm 快捷方式，保留用户已有窗口与远程会话。

已完成：增加默认关闭的后端权限与模型工具门禁，界面提供开启、关闭、取消和状态恢复。849 项 Rust/协议测试、156 项 renderer 测试及全部项目门禁通过；当前源码原生桌面验证真实 REA 分析、关闭时拦截、取消开启与审批中撤销。Windows x64 exe、NSIS 安装包、截图、构建记录和桌面快捷方式均已更新。真实 SSH 主机与用户模型服务待目标环境验收，参见 [验收记录](../../quality/rea-integration-validation.md)。
