# 界面可读性调整

目标：保留 TermHub 当前界面结构，增大偏小文字，并微调布局以适应更清晰的字号。

- 公共排版：最小辅助文字 12px，常规控件 13px，主要标签 14px；沿用离线字体和现有主题。
- AI：聊天正文与输入 15px，侧栏 14px；模式、模型、提示至少 12px。窄侧栏工具栏分行，保留完整可点击区域。
- 常用页面：检查首页、设置、连接表单和文件路径/列表，适度增加字号与行间距。
- 验证：当前源码原生 Windows 开发窗口，四种主题、自定义强调色、窄侧栏、短窗口和 125% 缩放；执行项目门禁与 CSS contract。
- 交付：重新编译 Windows 程序和安装包，更新桌面快捷方式，保留运行中的用户程序。

终端栅格字体仍由用户的终端字号设置控制。
