# AI 接入当前 SSH

聊天栏增加紧凑 SVG 按钮，复用当前已登录 SSH 会话。点击后校验终端、根窗格、会话 revision 与 Provider，读取 L2 上下文并启用半自动协作；再次点击恢复纯对话并取消上下文引用，SSH 连接继续保留。

不新建 SSH 登录或将模型部署到服务器。复用现有请求级上下文与逐次命令审批。接入过程中禁用重复提交与模式/Provider 切换；目标在异步操作中变化则终止并回退模式。完成回归测试、原生桌面验收、Windows 构建与桌面入口更新。

实现拆为 SSH 绑定校验、业务 SVG 控件与独立样式，面板仍小于 800 行。新增六项回归测试，原生 loopback SSH/Provider 已验证逐次审批、执行返回、取消接入与不可用状态；见 [验收记录](../../quality/ai-current-ssh-validation.md)。
