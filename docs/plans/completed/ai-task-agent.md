# AI 持续任务执行

目标：在现有终端侧栏提供按目标推进的任务流程，保留纯对话、目标确认、逐操作审批、REA 手动开关和中断恢复。

- 增加跨 Chat / Responses / Anthropic 的计划工具，持久化步骤并在侧栏展示。
- 将执行预算由 8 轮调整为 32 轮；有未完成计划却提前结束时最多提醒两次，仍未完成则明确暂停，不能标为完成。
- 工具被拒绝、连接改变或执行结果不确定时停止自动推进；保留步骤供用户继续。
- 任务完成需说明实际修改和验证结果；模型声明的步骤完成不等于独立验收。
- 验证：协议投影、计划参数校验、持久化/恢复、结束状态、前端与仓库门禁。真实第三方模型和用户 SSH 不使用测试凭据替代验证。

已完成：计划工具、侧栏步骤、32 轮执行预算、两次有界续行与暂停语义。类型/lint/格式、182 项 renderer、912 项 Rust/contract（2 项既有忽略）、Clippy、CSS contract 均通过；三种协议原生夹具各完成 13 轮任务，四主题窄侧栏通过。Windows 程序和 NSIS 安装包已构建，版本保持 2.3.1-beta.10。详见 [验证记录](../../quality/ai-task-agent-validation.md)。
