# 文件目录导航按钮

在本地与服务器文件窗格的路径栏添加两个图标按钮：返回上一级目录，以及进入唯一选中的子目录。用户已明确更正为进入选中目录，不实现浏览历史前进。

复用已有目录项和打开目录回调，避免另算路径或新增协议。根目录、断开连接、加载中、无目录选择和多选时按实际能力禁用按钮；支持主题提示、键盘操作和窄窗格。运行项目门禁及当前工作区原生桌面验收，重新编译 Windows 软件并更新桌面入口。

原生验收暴露了原有父目录项对 Windows 混合分隔符的计算问题；已在共享的 `withParentRow` 中修正，增加混合/尾随分隔符、驱动器根、POSIX 反斜杠文件名和共享根边界回归测试。按钮仍复用列表中的父目录项，不新增导航协议。

已于 2026-10-21 完成实现、门禁、原生验收与 Windows x64 EXE/NSIS 构建。桌面 TermHub 快捷方式已更新至 `release/TermHub-directory-navigation/TermHub.exe`，最终文件哈希及 CLI/MCP 验证通过。详见[验收记录](../../quality/file-directory-navigation-validation.md)。
