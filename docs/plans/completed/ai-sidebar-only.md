# 取消独立 AI 工作台

用户认为独立 AI 展示台冗余，移除首页工作台入口、聊天展开按钮、全屏布局、导航和旧事件入口。

- AI 功能统一由终端标题栏按钮打开侧栏。
- 保留 Provider、聊天历史、工作空间、附件、SSH、REA 和审批功能；不迁移或清理用户数据。
- 工作空间选择和移除在侧栏完成，删除操作复用确认弹窗。
- 清理独立工作台组件、专用 CSS、文案和当前使用说明。
- 原生验证首页、侧栏、历史、附件、REA、工作空间、主题与缩放；执行项目门禁。
- 编译 Windows 软件，更新桌面快捷方式。
