# AI 侧栏

点击窗口标题栏的机器人按钮打开或关闭 AI Copilot。AI 功能统一在侧栏中使用，首页不再显示独立 AI 工作台，也不再提供展开按钮。

## 持续解决任务

连接工作空间终端并选择半自动或全自动模式，确认本次目标后，直接描述要完成的任务。AI 会对多步骤任务建立计划，检查环境、执行操作、验证结果并汇报；成功步骤之间不需要反复发送“继续”。纯对话模式仍用于提问和讨论。

侧栏显示任务步骤与完成数量，步骤可折叠。半自动模式逐操作审批；全自动模式沿用现有危险命令限制，文件修改仍需确认差异。REA 仍需手动开启。

每次任务最多 32 轮模型调用。有未完成计划却提前结束时，系统最多提醒 AI 两次继续；仍未完成、操作被拒绝或连接发生变化时显示暂停，可以点击“继续任务”。计划和执行进度会保存，继续时检查当前状态，不自动重放已完成或结果不确定的修改。步骤状态由模型更新，实际完成情况以操作日志和验证结果为准；不会将未完成计划仅因回复结束标记为完成。

## 工作空间与历史

- 侧栏顶部下拉框选择工作空间；“独立对话”用于不关联目录的会话。
- `+` 按钮添加本地目录；连接 SSH 后，服务器按钮添加对应远程目录。
- 选中工作空间后显示目录路径，悬停可查看完整路径和所属主机。垃圾桶按钮经确认后移除工作空间；实际目录、文件和历史对话保留。
- 点击会话标题旁的返回箭头查看历史会话，支持搜索标题和消息正文；可通过工作空间下拉框筛选，结果显示匹配的正文片段。搜索在本地进行，不调用模型。
- 标题栏的对话图标也可切换历史列表。上翻阅读时，新回复不会强制滚回末尾；点击“回到最新消息”恢复跟随。
- “连接工作空间终端”打开对应本地或 SSH 终端并进入协作模式。选择目录本身不会读取所有文件；工具执行仍使用现有上下文和审批流程。

输入框草稿按会话保存，包括未发送的文字、附件、厂商和模型。切换会话后恢复各自的草稿，关闭再打开侧栏会回到上次对话；未建立对话的草稿按工作空间分别保存。附件内容保存在 `ai-attachments/`，`ai-drafts/` 只记录草稿文字和附件引用。

用户消息旁的铅笔按钮可编辑并重新发送；发送会建立一个新分支，原对话保持完整。消息旁的分支按钮可从所选位置创建新对话。分支复制此前的文字和附件，清除旧终端上下文、执行审批和任务状态，并切回对话模式；需要远程协作时重新连接和确认目标。

## 附件与工具

输入框的回形针按钮选择文件，也可拖入或粘贴文件。发送前可逐个移除；发送后随对话保存。文本、图片可预览，PDF 保留文件卡片，重试保留附件。

支持 UTF-8 文本/代码、PNG、JPEG、GIF、WebP 和 PDF。每条消息最多 8 个附件，每个最多 5 MB，合计最多 20 MB；文本/代码每个最多 128 KB。历史请求的附件内容按最近消息保留至 20 MB，较旧内容可能省略。图片、PDF 需要 Provider 与模型支持对应输入格式。

模型使用设置中配置的 Provider。SSH 按钮连接当前终端设备，REA 扫描图标手动开启分析能力；命令执行保留审批和危险命令限制。

输入框底部的模型菜单同时选择厂商和模型；旁边设置思考档位与“对话 / 协作 / 托管”模式。Enter 发送，Shift + Enter 换行。回复期间可编辑下一条草稿，结束后手动发送；停止按钮中止当前请求。输入框随文本增高到上限后内部滚动。

工具执行显示为状态步骤，已完成步骤默认折叠，可点击查看命令和输出。待审批、执行失败与错误输出保持可见。点击按钮有轻微缩放，支持系统的“减少动态效果”设置。

AI 修改文本文件时会先读取当前版本，再显示逐文件的修改前后内容。每个文件需要单独接受，托管模式也保留这一步；保存前发现文件被其他程序修改会拒绝覆盖。已接受的修改可在步骤卡片中撤销；撤销同样检查当前版本。手动文本编辑器保存后也提供撤销，存在未保存草稿时先保存或放弃草稿。恢复副本有数量和容量上限，较旧副本会清理。

附件在发送时交给 Provider，选文件和预览不发送给模型。附件保存在 `ai-attachments/`，工作空间保存在 `ai-workspaces.json`；取消独立工作台不会删除这些数据。

## 引用文件和日志片段

点击输入框的引用文件按钮，或在空输入框键入 `@`，可选择本地文件或当前 SSH 设备上的文件。工作空间目录会填入路径，点击“浏览”查看目录，点击文件打开预览；也可直接输入文件路径后读取。文件管理器中文件的“加入 AI 对话”菜单也会打开同一预览。

预览中调整起始行、结束行，只将选中的片段加入附件，自动记录文件路径、主机和行号。适合发送错误日志、配置或代码片段，每段最多 128 KB。点击“加入对话”后仍可检查、移除附件，点击聊天的发送按钮才会交给模型。预览使用现有文件读取能力，超大日志建议先在终端截取需要的范围。

SSH 文件引用绑定打开预览时的连接；切换设备或连接变化后需重新选择，避免从不同设备读取同名路径。引用文件只读取内容，不执行其中的命令。

## 中断恢复与上下文预算

回答和工具步骤会保存检查点。停止、网络中断或重启后，未完成任务显示“继续任务”；继续时保留已经收到的回答和步骤，重新取得当前终端上下文。继续任务仍须在原设备上进行，换设备应发起新任务。后台运行的命令显示累计输出和耗时，原任务的审批不会自动变成新操作的授权。

对话下方显示应用发送的上下文预算估算。长对话会将较早消息整理为本地摘要，展开可查看摘要内容与涉及的消息数；这不会删除本地聊天记录，也不会额外调用模型。该预算是应用控制的请求大小估算，不代表厂商声明的模型上下文上限。

本地工作空间支持真实命令执行，使用对应终端的 shell 和工作目录。修改操作保留审批，未知的本地脚本在托管模式下也要求确认；停止会取消子进程。普通本地/SSH 命令可运行至 30 分钟并持续显示日志和耗时；交互式认证与网络设备保留原有执行方式。

## 配置模型

打开侧栏设置 → AI Provider → 添加 Provider，选择厂商预设，填写对应 API Key 后保存。预设会填好地址和默认模型；可拉取模型列表或手动输入账号可用的模型 ID。连接测试会向该厂商发起真实请求。

能力检测可分别验证普通回答、流式、工具调用及图片理解，并分别显示结果。需要点击后才发起测试请求；工具测试只返回固定测试值，不会执行设备命令。REA 开启时显示运行时检查、准备和引擎检查阶段；发现工具列表不代表 Ghidra、IDA 或浏览器环境已经就绪。

## 目录同步

在文件管理器中右键目录，选择“目录同步”，填写本地和远程目录及传输方向，先预览再勾选文件。可按路径筛选，忽略规则支持 `*`、`?` 及目录名，默认忽略 `.git`、`node_modules`、`.DS_Store`。比较依据文件大小和修改时间，不能发现大小与时间都相同的内容变化。

只将选中的文件加入原有传输队列，支持查看进度、暂停和重试；目标端独有的文件保留。预览后源文件、目标文件或设备变化时需要重新预览。选择已有本地目录；不跟随符号链接或 junction，以免同步到选择范围之外。

| 厂商                                 | 接口方式                    | 设置要点                                            |
| ------------------------------------ | --------------------------- | --------------------------------------------------- |
| OpenAI / Responses 兼容服务          | Responses                   | 自定义服务按其文档填写 URL 和模型                   |
| Claude                               | Anthropic Messages          | Anthropic API Key，或支持 Messages 协议的服务       |
| Gemini                               | Google 官方 OpenAI 兼容接口 | Google AI Studio API Key，预设使用 `/v1beta/openai` |
| 通义千问                             | 百炼 OpenAI 兼容接口        | Key 与地址地域对应，预设为北京地域                  |
| DeepSeek、Kimi、智谱、豆包、硅基流动 | 各厂商 OpenAI 兼容接口      | 填写各自 Key；豆包也支持账号中的模型/推理接入点 ID  |
| Ollama、LM Studio                    | 本地 OpenAI 兼容接口        | 启动本地服务并填写已安装模型                        |

接入使用各家的 API Key，不使用 Codex / Claude / Gemini 的网页订阅登录。工具调用、图片和思考档位取决于所选模型和服务端；“模型能力配置”可修正自定义服务的能力。Gemini 本次接入覆盖对话、流式回复、图片与工具调用，不启用 Google File API 或 Google Search 内置工具。PDF 请使用支持当前附件格式的 Provider。

兼容处理会在工具循环中保留 Gemini 的工具签名和 Claude 的思考块，供模型继续执行使用；兼容 Chat 的推理上下文按消息 ID 私下保存，并绑定厂商、地址与模型，不作为聊天正文展示。

旧对话没有保存过的推理上下文无法补回。若 DeepSeek 的旧工具对话提示历史 reasoning 缺失，请新建对话；新版会为新回复保存所需信息。

接口依据：[Gemini OpenAI 兼容接口](https://ai.google.dev/gemini-api/docs/openai/)、[Claude 流式消息](https://platform.claude.com/docs/en/build-with-claude/streaming)、[百炼兼容接口](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)、[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)。会话布局参考 [Codex IDE 扩展](https://learn.chatgpt.com/docs/codex/ide)，保留 TermHub 的终端、SSH 和 REA 工作流。

长任务会按需压缩旧工具轮次，保留当前计划、近期操作摘要和最新完整结果；不会为了压缩截断模型签名。工具结果缺失时标为未知，不能视作成功或自动重做。压缩仅改变发给模型的临时上下文，原有活动记录与恢复检查点保留。预算是估算值，极大附件或最新结果仍可能超过模型窗口。实现与源码分析见 [Codex 核心适配](./quality/codex-core-analysis.md)。
